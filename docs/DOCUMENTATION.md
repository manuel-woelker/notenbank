# Notenbank Documentation Overview

## Where can I find the use case requirements?

The use case requirements can be found in the subfolder `./use-cases`.

Each subfolder is a separate use case:

- **[U1 Administration](./use-cases/U1%20Administration/U1%20Administration.md)** - Manage classes, students, and subjects
- **[U2 Assessment](./use-cases/U2%20Assessment/U2%20Assessment.md)** - Record assessments and calculate grades
- **[U3 Change Tracking](./use-cases/U3%20Change%20Tracking/U3%20Change%20Tracking.md)** - Audit trail for all data modifications

## Where can I find the tech stack?

Refer to [TECH-STACK.md](TECH-STACK.md) for information on the technologies used, and why they were chosen.

## Where is the example database documented?

See [EXAMPLE-DATABASE.md](EXAMPLE-DATABASE.md) for details on the separate
